docker ps: Mostra os containers que estão em execução.

docker ps -a (ou docker container ls -a): Mostra todos os containers, incluindo os que já foram finalizados.

Usamos o comando docker run ubuntu sleep 1d para manter o container Ubuntu em execução por um dia, pois o processo sleep impede que ele finalize imediatamente.

Vimos como interromper (docker stop).

Reiniciar (docker start) containers.

Interagir com eles em tempo real usando o docker exec.

Os comandos docker pause e docker unpause, que permitem pausar e retomar a execução de um container, mantendo seu estado.

Remover um container com o comando docker rm.

iniciar um container já com um terminal interativo usando docker run -it.

docker stop $(docker container ls -q): Para todos os containers em execução.

docker build -t nome/imagem:tag .: Constrói uma imagem Docker.

docker run -p host_port:container_port -d nome/imagem:tag: Executa um container Docker, mapeando as portas e rodando em modo detached.

Com a flag -v: docker run -it -v /caminho/no/host:/caminho/no/container ubuntu bash

Com a flag --mount: docker run -it --mount type=bind,source=/caminho/no/host,target=/caminho/no/container ubuntu bash - A flag --mount é a forma mais recomendada, pois é mais semântica.
